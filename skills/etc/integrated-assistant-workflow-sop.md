Integrated AI-Assisted Learning Workflow (SOP)
Foundational Concept Mapping (High-Level Architecture)
Action: Define core learning objectives for a new curriculum segment. Establish the “Master MOC” entry point.
Reasoning: Defining the high-level intent ensures that every note created serves the broader curriculum architecture rather than becoming an isolated “dead” data point.
Environment and Tool Selection (Semantic Hierarchy)
Action: Implement the Category-Subcategory-Title.md naming convention. Configure Foam settings to prioritize tag-based filtering and backlink visualization.
Reasoning: A flat folder structure minimizes friction. By using semantic naming, you ensure that fuzzy-finding and autocompletion in VS Code become your primary retrieval mechanisms, effectively creating a “virtual” organization.
Curriculum Atomicization & MOC Integration
Action: Deconstruct the curriculum into atomic note units. Create or update the relevant MOC file by tagging it with #MOC and populating it with wikilinks to these new units.
Reasoning: The MOC acts as the logical hub. By linking atomic notes to an MOC, you categorize concepts based on their relationship to the curriculum, rather than their physical location in a file system.
Literate Learning & MOC Curation
Action: Draft atomic notes using the category-subcategory-title naming convention. Titles must always be lowercase text. Embed relevant metadata in YAML front matter. Manually (or AI-assisted) index these notes into the associated MOC.
Reasoning: The MOC is the “syllabus” of your knowledge base. Maintaining it requires you to synthesize the notes, ensuring that you understand not just the fact, but the context in which it sits.
